ARTI 303 - Lab 04: Variables in Prolog
Task 1 - Unification queries and answers

1. ?- house = house.
   Result: true.
   Why: Both atoms are identical.

2. ?- house = abc.
   Result: false.
   Why: Different atoms cannot unify.

3. ?- edge(a,b) = edge(C,b).
   Result: C = a.
   Why: The structures match, and C takes the value a.

4. ?- edge(a,d) = edge(C,B).
   Result: C = a, B = d.
   Why: Each variable matches the atom in the same position.

5. ?- edge(C,B) = edge(a,d).
   Result: C = a, B = d.
   Why: Both arguments can be unified by assigning C and B.

6. ?- edge(A,f(g,h)) = edge(a,B).
   Result: A = a, B = f(g,h).
   Why: A matches a, and B matches the whole term f(g,h).

7. ?- edge(A,A) = edge(b,c).
   Result: false.
   Why: The same variable A would have to be both b and c.

8. ?- edge(A,A) = edge(b,b).
   Result: A = b.
   Why: Both appearances of A match b.

9. ?- A = B, B = f.
   Result: A = B, B = f.
   Why: A and B are linked, then both take the value f.

10. ?- A = B, B = f, A = e.
    Result: false.
    Why: A is already linked to B = f, so it cannot also equal e.
